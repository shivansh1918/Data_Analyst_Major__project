🏙️ Smart City Analytics – Major Project

📌 Project Overview

Smart City Analytics is my Major Data Analytics Project, developed to explore, analyze, and understand city-related data using data analytics tools and visualization techniques.

The main objective of this project is to transform raw data into meaningful insights that can support better decision-making and help understand different aspects of smart city development.

🎯 Project Objectives

- Analyze and understand the available dataset.
- Perform data cleaning and preprocessing.
- Apply Excel functions and analytical techniques.
- Create meaningful visualizations and reports.
- Develop interactive dashboards.
- Present analytical findings through a project presentation.

🛠️ Tools & Technologies Used

- Microsoft Excel – Data Analysis and Spreadsheet Operations.
- Power BI – Data Visualization and Interactive Dashboard.
- Python – Data Analysis and Processing.
- NumPy & Pandas – Data Manipulation and Cleaning.
- Matplotlib – Data Visualization.
